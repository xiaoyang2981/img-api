行为

站点名称 显示在前台左上角，默认「梦星的小图床」。
允许公开注册 关闭后首页会隐藏注册按钮，注册接口返回 403。通过注册创建的账户固定为成员。
随机接口默认返回 WebP 关闭后带有效 Token 的请求默认跳转原图；未认证请求始终只能取 WebP。可用 ?type=origin / ?type=webp 强制指定。
公开发布图片列表 关闭时 /list 需要登录（默认）。打开后任何人都能列出图库，只建议在私密站点使用。
单张上传上限 单位 MB，范围 1–500。
端口 保存在配置里，修改后重启生效；环境变量 PORT 优先级更高（当前进程使用 -）。仅站长可修改。

接口水印

只作用于上传时勾选「接口水印」的图片。通过 API 输出时会添加可见水印和不可见标识；直接访问 /i、/w 不添加。

水印文字 默认 ✨。自定义文字会用服务器字体渲染，建议使用简单英文或符号。
可见水印不透明度 0–1，默认 0.35。设为 0 时只保留不可见标识。
水印位置 默认右下角。
水印大小 按图片短边百分比计算，范围 1–30，默认 7。
水印颜色 可见水印的文字 / 图标颜色。

API 速率限制

游客每分钟 GET 次数 按 IP 统计，适用于没有携带 Token、也没有登录的请求。
注册用户每分钟 GET 次数 按账户统计，携带有效 Token 或已登录会话时生效。
Token 临时封禁时长 同一 Token 在短时间内多次触碰速率限制后自动封禁的默认时长，单位小时。

统计窗口为 1 分钟；保存后立即生效。站长使用系统固定额度，不在此页显示。账户页可以查看限流触发次数并手动封禁/解封。

邮箱验证

开启邮箱验证 开启后注册必须填写邮箱并验证验证码；忘记密码通过邮箱验证码重置。关闭时注册不需要邮箱。
SMTP 服务器
SMTP 主机 例如 smtp.qq.com、smtp.163.com。
SMTP 端口 常见：587（STARTTLS）或 465（SSL）。
SSL / TLS 465 端口通常需要开启；587 端口通常关闭并使用 STARTTLS。
SMTP 用户名 通常就是邮箱地址；不需要认证时可留空。
SMTP 密码 / 授权码 QQ、163 等邮箱通常需要填写“授权码”，不是登录密码。
发件地址 收件人看到的发件人，例如 图床 <you@example.com>。
发送测试邮件 使用已保存的 SMTP 配置发送一封测试邮件，确认服务器可以正常发信。
SMTP 尚未配置，请先填写并保存上方配置。

接口速查

接口说明
/api/v1rdV1 随机一张，302 跳转。包含已通过图片（含前台隐藏），?format=json 返回 JSON；未认证只能得到 WebP
/api/v2rdV2 图库随机一张，302 跳转。只使用 V2 接口图库中已加入的图片
/api/v1直接返回图片字节，不跳转；图库包含已通过图片（含前台隐藏）；可用 id 指定单张；?type=png 或 /api/v1.png 返回 PNG
/api/v2只从 V2 接口图库中已加入的图片随机；支持标签、类型和 JSON 参数；可在 /admin/v2 管理
/api/avatar?user={username}头像服务，默认 JPG，?type=png 输出 PNG；省略用户时使用当前 Token 用户或站长
/i/{file}原图；未认证会跳转到 WebP，需登录会话或 Token
/w/{file}WebP 版本，长期缓存
/list分页列表，需登录或 API Token（除非开启公开）
/info/{id}单张图片信息
/stats数量与体积统计
POST /admin/api/upload上传，使用登录会话或 Authorization: Bearer <token>

给其他服务用：/api/v1rd?format=json
