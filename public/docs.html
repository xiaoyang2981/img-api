使用文档

本文档面向所有访问者、注册用户和站点管理员，按实际操作顺序说明图片浏览、账户注册、上传审核、个人信息管理和 API 接入方式。按照对应章节逐步操作即可完成配置。

开始使用 查看 API 接口

快速开始

第一步：浏览图片 打开首页，等待随机图片加载完成。点击当前图片或「换一张」即可刷新。
第二步：注册或登录 如果需要上传图片、管理自己的图片或调用 API，请先注册账户并登录。
第三步：开始使用 普通用户可进入后台完成上传；API 使用者请在「个人信息」页创建 Token，然后参考下方接口章节接入。
仅浏览图片时无需注册。 游客可以直接查看首页随机图片，也可以通过公开接口获取图片。

浏览图片

首页会从已通过审核且允许在前台展示的图片中随机选择一张。每次点击图片或「换一张」都会重新请求一次随机图。

  • 如果首页提示图库为空，说明当前没有通过审核且允许展示的图片。
  • 图片被管理员或上传者隐藏后，不会继续出现在首页、随机接口、公开列表和前台统计中。
  • 右上角主题按钮可以切换深色和浅色模式。
  • 页面底部的站点名称和版权信息由站长在后台设置。
注意： 直接打开已被隐藏或尚未通过审核的图片地址时，匿名访问可能返回 404。图片上传者、审核员、管理员和站长仍可在后台预览。

注册与登录

注册账户

  1. 打开首页右上角的「注册」入口，或直接访问 /register。
  2. 填写用户名、密码和显示名。用户名长度为 3–32 位，密码至少 8 位。
  3. 如果站点开启了邮箱验证，请填写邮箱并点击「发送验证码」。
  4. 将收到的 6 位验证码填入输入框，阅读并确认后提交注册。

验证码在 10 分钟内有效，同一邮箱 60 秒内不能重复发送。注册的账户默认身份组为「成员」。

登录与找回密码

  1. 打开 /login，输入用户名和密码登录。
  2. 登录后会根据身份组进入后台、审核台或个人信息页。
  3. 忘记密码时，使用登录页的「忘记密码」入口，通过当前绑定邮箱接收验证码并重置密码。
请妥善保管账户信息。 不应将密码、邮箱验证码或 API Token 提供给他人。

身份组说明

身份组权限概述
站长全部权限，包括站点设置、账户管理、审核、图片管理、端口设置和 Token 封禁管理。
管理员审核、图片管理、账户管理和普通设置；不能修改端口等仅站长可改的配置。
审核员可访问审核台处理待审核图片，并查看个人信息；不能上传图片。
成员登录后可上传图片、管理自己的图片，并查看个人信息。

上传与审核

上传图片

  1. 使用成员、管理员或站长账户登录，进入后台首页 /admin。
  2. 将图片拖入上传区域，或点击上传区域选择文件。支持 PNG、JPG、WebP、GIF 和 AVIF，单张大小不能超过站长设置的上限。
  3. 按需填写标签、标题和来源。标签使用英文逗号分隔，例如 wolf,dragon。
  4. 选择文件后会先弹出确认窗口。核对文件名、缩略图、标签、标题和来源后，点击「确认上传」。
  5. 上传完成后图片状态为「待审核」，此时不会出现在前台图库中。

审核流程

  1. 审核员、管理员或站长进入审核台 /admin/review。
  2. 在待审核、已通过、已拒绝标签之间切换并查看图片。
  3. 点击「通过」后，图片才可能进入前台；点击「拒绝」则不会进入图库。
  4. 审核通过后，如果不需要继续在前台展示，可以在后台图片卡片下方点击「隐藏前台」。
重复图片： 系统会按文件内容去重。相同图片重复上传时可能直接返回已有记录，不会重复占用存储空间。
前台展示开关： 已通过审核的图片可以单独隐藏或恢复展示。隐藏后不会进入首页、/random、/api/v1、/list 和前台统计。

个人信息与账户安全

登录后访问 /admin/profile，可以管理显示名、邮箱、密码和 API Token。

基本资料

  • 可以修改显示名，显示名会出现在前台、后台和账户信息中。
  • 用户名是账户唯一标识，不可修改。

绑定或修改邮箱

  • 首次绑定邮箱时，验证码会发送到新邮箱，用新邮箱完成验证。
  • 修改已经绑定的邮箱时，验证码会发送到当前邮箱，验证通过后才能改成新邮箱。
  • 邮箱修改成功后，其他设备的登录会话会失效。

修改密码

  • 需要填写当前密码，并向当前邮箱发送验证码。
  • 新密码至少 8 位，且需要再次确认。
  • 修改成功后，其他设备会退出登录，当前会话保留。
  • 未绑定邮箱时不能修改密码，请先完成邮箱绑定。

API Token

  • 在「API Token」区域点击「创建 Token」。
  • Token 只会在创建弹窗中显示一次，请立即复制并妥善保存。
  • 关闭弹窗后无法再次查看完整 Token，只会保留尾号。
  • 如果 Token 遗失或需要更换，请先点击「吊销 Token」，再重新创建。
  • Token 被临时封禁时不能创建新 Token，但可以吊销；需要等待自动解封或联系管理员解除后才能重新创建。
不要把 Token 当作公开链接参数分享。 在支持请求头的场景中，优先使用 Authorization 请求头；?token= 适合图片标签、HMCL 等无法设置请求头的场景。

API 接入

API 地址以当前站点地址为前缀。以下示例中的 http://your-host:2618 请替换为您实际访问的站点地址。

接口用途说明
GET /random随机图 302默认跳转到 WebP，支持标签、类型和 JSON 参数。
GET /api/v1直接返回图片字节不返回 302，适合不能跟随跳转的客户端。
GET /api/v1.png直接返回 PNG兼容只支持 PNG 的客户端。
GET /list分页图片列表默认需要登录或携带 Token；站长可设置为公开。
GET /info/{id}单张图片信息隐藏图片对匿名访问返回 404。
GET /stats前台统计只统计允许前台展示的已通过图片。
GET /i/{file}原图直链长期缓存；不做随机限流。
GET /w/{file}WebP 直链长期缓存；不做随机限流。
GET /health健康检查返回服务状态。

随机图参数

参数取值说明
tag如 wolf,dragon按标签筛选；多个标签默认任意匹配。
tagModeany / all默认 any；all 要求同时包含全部标签。
typeorigin / pngorigin 强制原图；png 适用于 /api/v1 系列；/random 默认按站点设置返回 WebP 或原图。
formatjson返回图片信息 JSON，而不是直接跳转或返回字节。

基础调用示例

<img src="http://your-host:2618/random?tag=wolf" alt="随机图片">
curl -H "Authorization: Bearer <TOKEN>" "http://your-host:2618/random?format=json"
{
  "id": "图片 ID",
  "url": "图片直链",
  "origin": "原图地址",
  "webp": "WebP 地址",
  "width": 1920,
  "height": 1080,
  "tags": ["wolf", "dragon"]
}

HMCL 等不支持跳转的客户端

HMCL 等客户端可能不会跟随 HTTP 302 跳转。请直接使用返回图片字节的接口，并优先使用 PNG 后缀：

http://your-host:2618/api/v1.png?token=<TOKEN>
  • 如果不带 Token，将按游客速率统计。
  • HMCL 会缓存网络背景图。更换图片后如果长期不更新，可以在地址后增加一个随机参数，或清理 HMCL 的图片缓存。
  • 如果服务器使用 HTTPS，请确保客户端信任对应证书。

API Token 与速率限制

为了防止异常爬取，随机图和列表接口按 1 分钟窗口限流。携带有效 Token 或使用已登录会话可以按注册用户额度统计。

身份默认额度统计方式
游客200 次/分钟按 IP 地址
注册用户2000 次/分钟按账户
站长2,000,000 次/分钟系统固定额度

Token 携带方式

Authorization: Bearer <TOKEN>
X-API-Token: <TOKEN>
http://your-host:2618/random?token=<TOKEN>
  • 没有携带 Token 时，已登录会话按注册用户统计，否则按游客统计。
  • Token 无效时返回 401，不会降级为游客。
  • 超过额度时返回 429，响应包含 Retry-After 和速率信息响应头。
  • 同一 Token 在 10 分钟内多次触发限流，会被临时封禁；默认封禁 12 小时。
  • 封禁期间该 Token 的请求返回 403，网页登录会话仍可正常使用。
Token 遗失时： 进入个人信息页，先吊销当前 Token，再点击创建。系统不会保存可再次显示的完整 Token 明文。

管理员指南

以下功能仅对相应身份组开放。管理员操作会影响其他用户和前台展示，请确认对象后再执行。

后台首页 /admin

  • 上传图片、查看图库、编辑标签/标题/来源、删除图片。
  • 已通过审核的图片卡片下方有「隐藏前台 / 显示前台」按钮。
  • 成员只能管理自己上传的图片；管理员和站长可以管理全部图片。

审核台 /admin/review

  • 处理待审核图片，执行通过、拒绝或重新打回待审。
  • 审核结果决定图片能否进入前台图库；前台展示开关是独立设置。

账户管理 /admin/users

  • 站长可创建管理员、审核员和成员；管理员只能创建审核员和成员。
  • 可查看账户 Token 尾号、限流触发次数和封禁状态。
  • 可对其他可管理账户执行 Token 封禁、调整封禁时长或解除封禁。
  • 自己的邮箱和密码请在个人信息页修改，账户管理页不提供自助修改。

图床设置 /admin/setting

  • 站点名称、公开注册、前台列表、上传大小和 API 速率。
  • 站长额外拥有端口和 SMTP 邮箱配置权限。
  • Token 临时封禁时长可在此统一调整，默认 12 小时。
  • SMTP 配置完成后，可以发送测试邮件验证发信是否正常。

常见问题

首页没有图片怎么办？

可能是图库为空、所有图片都在待审核，或图片已被隐藏。请等待审核通过，或联系站长检查图库状态。

访问 /random 返回 404？

表示当前没有符合标签条件的已通过图片，或没有允许前台展示的图片。请减少标签条件后重试。

返回 401 是什么原因？

通常表示 Token 无效或已过期。请到个人信息页复制当前 Token；如果 Token 已遗失，请吊销后重新创建。

返回 403 是为什么？

可能是 Token 多次触发限流后被临时封禁。请等待封禁结束，或联系管理员解除。

返回 429 怎么办？

表示请求过快。请根据响应中的 Retry-After 等待后重试；长期使用建议注册账户并携带 Token。

上传后前台看不到图片？

上传后需要审核通过，并且图片必须处于「前台展示」状态。请先在后台确认状态，再等待审核员处理。

图片直链打不开？

图片可能尚未通过审核或被隐藏。上传者、审核员、管理员和站长可在登录状态下预览。

收不到邮箱验证码？

请检查垃圾邮件目录，确认邮箱地址正确，并等待 60 秒后重试。如果仍然收不到，请联系站长检查 SMTP 配置。

忘记密码怎么办？

在登录页使用「忘记密码」，通过绑定邮箱接收验证码重置。未绑定邮箱的账户需要联系管理员处理。

为什么不能修改密码？

修改密码需要当前邮箱验证码。请先在个人信息页绑定邮箱；如果仍然不可用，请联系站长检查邮件服务。

HMCL 背景图不更新？

请使用 /api/v1.png 或 /api/v1?type=png，并清理 HMCL 的网络图片缓存。也可以更换 URL 参数后重新添加。

如何切换深色/浅色？

点击页面右上角的主题按钮即可切换，选择会保存在浏览器中。

安全须知

  • 请使用 HTTPS 访问站点，避免密码、Token 和验证码在不安全网络中传输。
  • API Token 等同于账户访问凭证，不要公开发布、截图或提交到代码仓库。
  • 不要在不可信页面填写邮箱验证码；验证码只用于当前操作。
  • 发现异常请求、Token 泄漏或账户异常时，请及时吊销 Token、修改密码并联系站长。
  • 请遵守站点使用规则和当地法律法规，不要利用接口进行高频爬取、攻击或侵权传播。
  • 管理员在执行封禁、隐藏、删除等操作前，应确认目标账户或图片，避免误操作。

如需进一步协助，请联系站点站长或管理员。联系前请准备好账户名、发生时间和相关请求地址，以便快速定位问题。
